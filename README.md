# VibeCheck 低保真原型

VibeCheck 是面向 Vibe Coding 创作者的作品发现、比较、发布与生命周期资产平台。本仓库当前用于开发首期可点击低保真 Web 原型，首期品类限定为公开可访问的 AI 学习与题库 Web 工具。

## 当前阶段

低保真原型开发。实现顺序与验收要求以 `设计文件/VibeCheck低保真原型Codex开发任务书.docx` 为准，并按 T00—T57 逐任务推进。

## 原型范围

- 社区浏览：作品广场、分类、最新动态与关于说明。
- 高意图发现：统一搜索、意图确认、同类分析、二至五个作品比较与行动记录。
- 作者链路：发布前地址查重、新作品发布、已有档案作者身份验证、版本与状态更新。
- 用户资产：收藏、关注更新、比较记录、草稿、作品与通知。
- 运营维护：作品、证据、状态、审核、重复合并、作者归属与操作留痕。

本阶段不实现真实后端、生产数据库、真实认证、网页抓取、模型调用、状态监测、支付、私信、排行榜或商业成功判断。
