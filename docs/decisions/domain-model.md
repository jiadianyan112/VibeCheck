# 领域模型与状态边界

## 作品是全站主键

所有卡片、详情、更新、比较、互动、证据和后台操作都引用 branded `ProjectId`。作者身份验证只改变作品与作者的关联及编辑权限，不创建新的 `ProjectId`。

## 当前状态、技术检查与历史事件分离

- `Project.accessStatus`：前台当前访问状态，可包含暂停、结束和疑似迁移，但必须受证据约束。
- `Project.httpCheckStatus`：HTTP、DNS、证书、超时、重定向等技术观测，不能表达作者意图、暂停、结束或失败。
- `LifecycleEvent`：追加式历史事实，保留事件时间、来源、前后值和争议状态；当前字段变化不能删除历史。

`canBeProducedByTechnicalCheck` 明确阻止技术检查直接产生 `paused` 或 `ended`。

## 关键字段事实包装

`FieldFact<T>` 强制调用方处理 `known` 与 `unknown` 两种状态。两者都保留证据 ID、时效、最后验证时间、争议状态和推断置信度。未知值只有原因，没有可供业务使用的替代值，页面不得用生成摘要补写。

## 固定枚举

访问、技术检查、事件、审核、证据、分类、输入输出、练习反馈、资产、关系、作者关联和通知均使用只读枚举推导的联合类型，不使用宽泛字符串。自由文本只用于名称、定义、说明和用户输入。
