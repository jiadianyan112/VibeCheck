## 四条核心流程

| 流程 | 页面路径 | 关键要求 | 实现任务 | 集成验收 |
|---|---|---|---|---|
| F01 广场到高价值动作 | P01/P02/P03 → P08 → 收藏、关注或比较 → P09 | 返回保留滚动和筛选；未登录动作回放；比较不要求登录 | T14—T19、T27—T35 | T52、T56 / U01、U03 |
| F02 查同类到行动 | P05/P06 → P07 → 比较栏 → P09 → 决策 | 原始查询保留；解析可编辑；精确与相邻分区；2—5 个比较 | T22—T26、T32—T35 | T52、T56 / U02 |
| F03 发布与重复分流 | P10 → 地址检查 → P11 或 P08/P12 | 必须先查重；重复默认查看详情；身份验证是低频权限分支 | T36—T42 | T52、T56 / U04、U05 |
| F04 更新与回访 | P15 → P13 → P08 时间线 / P04 动态 / P16 通知 | 前后值留痕；更新生成事件；公开历史不可覆盖 | T41、T45、T46 | T52、T56 / U06 |
