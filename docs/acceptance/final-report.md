- `/admin/evidence` 是信息占位；证据核对、状态标记与日志集中在作品编辑页。
- 后台只保证基础窄屏提示与内部表格滚动；主要面向桌面验收。
- Vite 报告生产主脚本超过 500 kB；本地原型流程和响应式测试正常。
- `npm audit` 报告 React Router 不稳定 RSC Action 公告。当前纯客户端 SPA 不使用 RSC、SSR、loader 或 action，因此不具备该路径；升级到 8.3.0 需要同步主版本包结构和 React 基线，留作正式工程迁移。
