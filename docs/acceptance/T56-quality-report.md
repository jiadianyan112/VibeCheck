## 失败与修复

- U04 最初在自动提取完成前点击“保存并继续”，造成测试与异步状态竞态；改为等待作品名称写入后再继续。
- U03 的资产名称同时出现在标题和事件摘要中，严格定位歧义；改用可访问标题角色定位。
- U05 预期文案使用“等待人工审核”，实际规范状态名为“待人工审核”；改为验证真实状态名和“无可靠预计时间”边界。
- U01 不再假设卡片正文重复显示搜索词，而是验证查询标题、作品身份和具体匹配内容。

以上均为验收脚本定位或同步问题，没有跳过业务逻辑。

## 依赖与剩余风险

- `react-router-dom` 固定为 7.18.2，避免无意漂移。`npm audit` 仍报告 GHSA-qwww-vcr4-c8h2；该公告影响不稳定 RSC Action 请求路径，本仓库是纯客户端 `BrowserRouter` 静态原型，不含 RSC、SSR、loader 或 action，因此当前实现没有对应攻击面。
- 官方修复仅在 React Router 8.3.0；v8 同时移除 `react-router-dom` 并把最低 React 提升到 19.2.7，属于单独的主版本迁移，不在最终低保真交付中冒险引入。
- lint 的 15 条 Fast Refresh 警告来自组件文件同时导出帮助函数，不影响构建或运行。
- 659.02 kB 单包提示是后续性能优化项；当前本地原型加载与主流程测试正常。
