# 发布流程优化验收记录

验收日期：2026-10-03。参考：[Watcha 作品提交指南](https://docs.watcha.cn/post/submit-product-guide/)。本次在现有 React/localStorage 低保真原型中实施，经用户确认的范围为站内发布流程及下一阶段作品墓地准备。

## 实施结果

| 要求 | 实施与验证 |
| --- | --- |
| 基础信息 | 必填提交者关系；可选团队/开发者、独立 Logo；原截图字段继续作为封面 |
| 介绍与媒体 | 可选详细介绍、多张详情图、bilibili/b23 HTTPS 视频；提供的链接必须合法 |
| 致谢 | 多条名称、说明和可选公开地址，可添加或删除；不推导作者身份或资产许可 |
| 自由填写 | 各步骤与最终预览可直接切换；编辑自动保存，返回同一地址重新检查保留已填内容及草稿 ID |
| 提交门槛 | 两品类使用各自必填字段；最终预览汇总错误并链接到对应步骤；界面与服务入口统一校验 |
| 地址检查 | 未通过、超时或重复档案阻止首次发布；新检查结果同步到已有可编辑草稿，重复消除后可恢复 |
| 审核与发布 | 预览、冻结提交版本、后台审核和发布详情保留新增元数据；修改草稿不改写当前提交版本 |
| 退回修改 | 只有显式确认重新提交才替换提交版本；退回状态不提供可能触发重提的刷新按钮 |
| 旧记录兼容 | 新字段在类型上可选；旧发布仍可读取，未声明关系的旧草稿需补齐后提交 |
| 墓地准备 | [准备说明](../submission-graveyard-readiness.md)包含已有档案沿用稳定 ID、首次历史收录、证据、未知日期、权限与资产许可规则及验收场景 |

媒体采用公开 URL 输入，没有文件上传服务。作品墓地目前完成准备说明，页面、存储模型与接口留待下一阶段实现。网络异常不自动变成作品结束，提交者关系自述不授予作者管理权限。参考平台的审核时限、预告发布和徽章没有被转为本平台服务承诺。
