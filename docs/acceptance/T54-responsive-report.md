## 基线问题与修复

| 问题 | 根因 | 修复 |
| --- | --- | --- |
| 360px 详情页被撑宽 | 单列 Grid 的 `1fr` 仍接受内容最小宽度，详情内容把隐式轨道撑出视口 | 统一使用 `minmax(0, 1fr)`，并允许详情子项收缩与换行 |
| 360/390 顶栏搜索按钮文字被挤成竖排 | 品牌、全局搜索和菜单同时占用窄屏横向空间 | 416px 以下隐藏顶栏搜索框，在移动菜单中保留明确“搜索作品”入口 |
| 固定比较栏遮挡卡片按钮 | `.page-with-bottom-space` 被后声明的 `.page-container` padding 覆盖 | 提高底部安全区选择器优先级，并为操作控件增加滚动安全边距 |
| 详情核心操作与比较栏可能竞争底部空间 | 两组高价值操作均需要在移动端持续可达 | 详情操作栏固定在比较栏上方，横向滚动；自动化直接比较两栏几何边界 |
| 移动筛选占据过长首屏 | 桌面粘性侧栏在移动端仅变为普通长列表 | 搜索与专题筛选改为原生 `details` 抽屉；桌面 CSS 强制展开内容 |
| 发布步骤在单列中纵向过长 | 侧栏步骤列表直接堆叠 | 进度摘要保留，步骤改为横向滚动标签；正文和输入仍为 16px 基准 |
| 弹层、抽屉和后台表格窄屏密度不稳 | 桌面 padding 与表格宽度直接沿用 | 弹层改为底部对齐、使用 `100dvh` 上限；抽屉占满窄屏；后台显示窄屏提示并仅在表格容器内滚动 |
