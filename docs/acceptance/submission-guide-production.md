# 发布指南正式版迁移验收

日期：2026-10-03。来源：[Watcha 作品提交指南](https://docs.watcha.cn/post/submit-product-guide/)。正式版基线：`4eca683`，部署分支：`codex/actual-experiences`。

## 交付内容

- 在正式发布页补充提交者关系、团队或组织、详细介绍、Logo、详情图 URL、bilibili/b23 视频及多条致谢。关系为自述，不授予作者权限。
- 章节可自由填写；旧设备草稿与新增字段合并，自动保存半成品。已有真实认证、同源 API、图片上传/裁剪/排序、安全处理及账户隔离保持原有链路。
- 最终预览完整显示字段和已上传截图，缺项提供定位链接。保存和预览不提交，点击“确认并提交审核”后重新校验，沿用冻结预览哈希和幂等凭据。
- 新元数据随 `project_core.publication_details` JSON 快照保存。审核后台读取冻结提交版本；审核通过后公开作品详情显示介绍、媒体链接和致谢。旧提交和历史作品无需新增字段即可读取。
- 作品墓地后续合同、历史身份、未知日期、证据、稳定 ID 和权限边界见 [准备说明](../submission-graveyard-readiness.md)。专门墓地提交入口尚未开放。

- 基础库、API 与 Worker 测试：402 项通过；workflow 21 项包含其中。
- 完整生产构建和最终 Web 构建通过；合约校验 94 条路径、106 个操作。
- 发布浏览器专项：12 项通过，覆盖 360/390/1280/1440 视口、完整元数据、自动保存后刷新、预览不提交、显式确认、错误定位、网络重试、幂等凭据、访客登录恢复、图片及 WCAG A/AA 审计。10 项按现有测试配置跳过重复移动项目，360px 原生移动项目独立执行通过。
- ESLint：0 错误，18 个既有 React Fast Refresh 警告。生产文案检查通过。
- JS gzip-9：248,211 bytes，低于原预算 251,435。CSS 基线精确为 21,504 bytes；新增预览与元数据样式增加 638 bytes，当前 22,142。CSS 门槛设为 22 KiB（22,528），保留检查及 386 bytes 余量。

## 发布与回退

1. 将本次提交快进推送到既有部署分支 `codex/actual-experiences`，使用现有 Northflank Git 集成构建 Web/API 和 Worker。
2. 核对 GitHub quality 检查（包含 PostgreSQL 集成夹具），以及两个 Northflank 部署均为同一提交且成功。
3. 核对线上 `/health/ready` 的数据库健康、页面响应和构建资源。现有健康接口的 commit 可能为 `unknown`，此时以部署记录 SHA 和实际资源哈希共同确认版本。
4. 如需回退，先恢复 Web/API 和 Worker 至基线 `4eca683` 的同一镜像版本。新增字段位于快照 JSON；已有记录无需回填，新快照和旧快照均保持可读取。

部署是否完成以平台部署状态与线上验证为准；本文件记录准备与验证证据，不单独宣称已经上线。
