# T55 无障碍与键盘操作审计

## 审计范围

- 游客核心页：作品广场、搜索、详情、比较、发布入口、登录、关于。
- 受保护流程：登录弹层、发布多步骤表单、作者身份材料。
- 键盘主任务：搜索与意图确认、加入比较、比较决策、登录续办、发布地址检查与表单校验。
- 交互组件：Modal、Drawer、Tabs、移动比较标签、比较矩阵滚动区、发布步骤滚动区。
- 标准：axe WCAG 2 A/AA 与 WCAG 2.1 A/AA；人工检查语义标题、landmark、label、焦点顺序、错误关联、状态提示和不依赖颜色。

## 基线问题与修复

| 严重度 | 基线问题 | 影响 | 修复与证据 |
| --- | --- | --- | --- |
| Serious | Toast 在普通 `div` 上使用禁止的 ARIA 属性 | 所有页面 axe `aria-prohibited-attr` | 改为命名 `section` live region；七条公共路由 axe 复测为零违规 |
| Serious | 作品详情的 `dl` 含 `dt/dd` 之外的直接交互子节点 | 屏幕阅读器可能错误解析字段与来源按钮关系 | 每个事实字段使用合法分组，来源按钮进入对应 `dd`；axe `definition-list` 复测通过 |
| Serious | 移动发布步骤列表可横向滚动但不能获得键盘焦点 | 键盘用户无法滚动完整步骤 | 为步骤列表增加 `tabIndex=0` 和可访问名称；移动 axe `scrollable-region-focusable` 通过 |
| High | Modal/Drawer 只响应 Escape，Tab 可离开弹层 | 背景控件可能被误操作，焦点上下文丢失 | 统一焦点陷阱；支持首尾循环、Escape、无可聚焦项兜底和触发点恢复 |
| High | 标签页全部进入 Tab 顺序且无方向键 | 键盘操作不符合 Tabs 模式 | 通用 Tabs 与移动比较使用 roving tabindex，支持左右方向键、Home、End |
| Medium | 比较决策、发布和身份材料的汇总错误未关联到输入控件 | 读屏用户听到错误但难以定位 | 增加 `aria-invalid`、`aria-describedby`、稳定错误 ID，并在提交失败后聚焦第一个无效控件 |
| Medium | Modal/Drawer 标题使用固定 ID | 多实例时可能产生重复引用 | 使用 React `useId` 生成实例级标题 ID |

## 自动化结果

- 公共与登录后 axe：9 个页面／状态，桌面与移动均为 WCAG A/AA 零违规。
- 键盘：Modal/Drawer 焦点循环与恢复、搜索到比较决策、登录续办、发布错误定位、移动比较标签方向键均通过。
- 焦点恢复：Escape 关闭后返回原“收藏”或“展开证据”按钮。
- 多步骤错误：清空“一句话定义”后提交，焦点进入该字段，`aria-invalid=true` 且错误提示通过 `aria-describedby` 关联。
- 卡片多操作：标题链接、收藏和比较保持同级独立控件，不存在交互元素嵌套。
- T55 Playwright：23 项通过，5 项按桌面／移动职责预期跳过。
- 单元测试：57 个文件、258 项全部通过。

## 人工语义检查

- 页面核心区域使用唯一主标题与 `main`；页内区块由可见标题命名。
- 全局导航、面包屑、移动导航和比较维度均有区分性名称。
- 表单使用显式或包裹式 label；必填选择组使用 fieldset/legend。
- Toast、加载、成功与错误状态分别使用 `aria-live`、`status` 或 `alert`，状态不只依赖颜色。
- 比较“未知、过期、异常、有差异”等均保留文本标签；颜色仅作辅助。
- 桌面比较矩阵与移动发布步骤的滚动区域可通过键盘进入。

## 结论

T55 验收通过。axe 核心审计无严重问题，键盘可完成任务书要求的搜索、加入比较、比较、登录、发布和弹层关闭；Modal、Drawer 与表单校验均有明确的焦点落点与恢复路径。
