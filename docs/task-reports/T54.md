# T54 完成响应式与移动端关键流程

## 实施摘要

系统检查并修复 360、390、768 和桌面视口的导航、筛选、详情操作、纵向比较、发布进度、弹层、抽屉和后台窄屏表现。新增四组移动 Playwright 烟雾测试，所有适配均保留原有关键字段和操作。

## 前置条件检查

- [x] T52 四条核心流程已贯通。
- [x] T53 统一场景矩阵可用于固定状态回归。

## 主要改动

- 移动导航：416px 以下收起顶栏搜索，在菜单中增加“搜索作品”入口。
- 搜索与专题：桌面粘性筛选改造为移动原生折叠抽屉，URL 筛选行为不变。
- 全局 Grid：单列轨道改用 `minmax(0, 1fr)`，修复详情页内容最小宽度溢出。
- 详情：移动核心操作固定在比较栏上方，两栏使用独立层级和底部安全区。
- 比较：保留既有纵向维度、横向作品标签和固定行动栏，不回退到缩小桌面表格。
- 发布：移动步骤变为横向滚动，表单正文保持单列和正常字号。
- 弹层／抽屉：窄屏底部对齐、动态视口高度限制和全宽抽屉。
- 后台：保留基础窄屏提示、横向导航和表格内部滚动，不重做后台移动工作台。
- `e2e/responsive.spec.ts`：四视口溢出扫描、搜索比较、发布基础流程、弹层和后台烟雾测试。
