# T36 实现发布入口与地址检查

## 实施摘要

接通受保护的发布入口和固定身份登录回跳，完成公开 URL 的协议补全、即时格式校验，以及格式、安全、访问、查重、品类五项独立检查。检查可取消且不会隐式创建草稿；首次访问超时允许保存可恢复草稿，但继续发布保持阻断。

- [x] 未登录用户点击发布先进入固定身份登录，完成后返回 `/submit`。
