# T08 创建事件、证据、关系与用户资产模拟数据

## 实施摘要

为固定作品补充版本、生命周期事件、字段证据、相似／替代／复用关系、结构化评论、匿名与登录用户的收藏、关注、比较、决策、草稿、身份验证和通知数据。

## 改动文件

- `src/mocks/evidence.ts`、`events.ts`、`versions.ts`、`relations.ts`：可信事实与历史数据。
- `src/mocks/community.ts`：结构化评论与审核状态。
- `src/mocks/userAssets.ts`：用户、比较、决策、草稿、验证、通知与个人资产。
- `src/mocks/projects.ts`：关联已有作品的版本、事件和关系 ID。
- `src/mocks/dataset.test.ts`：引用完整性与状态边界测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 详情时间线、动态、证据、关系、评论和个人中心具备稳定数据。
- [x] 版本、迁移线索、异常、暂停、结束、新增资产和复用关系均有样例。
