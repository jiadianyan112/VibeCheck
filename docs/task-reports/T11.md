# T11 实现全局应用框架与导航

## 实施摘要

建立固定前台导航和独立后台框架，包含 Logo、一级导航、全局搜索、比较数量、发布、通知、头像、移动端折叠菜单与后台侧栏。未登录访问受限入口时携带 `from` 参数进入登录页。

## 改动文件

- `src/components/FrontstageLayout.tsx`：前台框架、搜索、导航和权限入口。
- `src/components/AdminLayout.tsx`：后台框架和侧栏。
- `src/app/router.tsx`：按前后台布局嵌套路由。
- `src/styles/global.css`：固定导航、后台布局和移动端规则。
- `src/app/router.test.tsx`：共享导航、高亮、权限链接和后台导航测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 所有前台页面共享固定导航，当前路由高亮。
- [x] 公共浏览不要求登录，发布、通知和个人中心执行权限分流。
- [x] 后台使用独立且一致的管理框架。
- [x] 移动端菜单可折叠并保留核心入口。
- [x] 类型检查、测试和构建通过。
