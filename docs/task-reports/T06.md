# T06 定义领域类型与枚举

## 实施摘要

依据作品字段字典和状态机定义严格领域类型、branded ID、固定枚举、未知／时效／争议元数据与状态边界函数；明确作品主键、当前状态、技术检查和生命周期历史的区别。

## 改动文件

- `src/types/domain.ts`：领域对象、枚举、事实元数据和状态边界。
- `src/types/domain.test.ts`：技术检查与暂停／结束边界测试。
- `src/types/index.ts`：公共领域类型出口。
- `docs/decisions/domain-model.md`：类型关系和状态边界说明。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 关键枚举不使用宽泛字符串。
- [x] 关键字段支持未知、过期、来源和争议元数据。
- [x] 当前状态、技术检查和生命周期事件分别建模。
- [x] 作品、作者、版本、事件、资产、关系、证据、比较、决策、发布、身份验证和通知均有严格类型。
- [x] 类型检查、12 项测试和生产构建通过。
