# T10 建立全局状态、持久化与事件日志

## 实施摘要

建立 AppState、reducer、Context、localStorage 持久化、匿名比较与账户合并、一次性待执行动作、草稿、决策、通知、场景切换和内存事件日志，并提供最小调试入口和一键重置。

## 改动文件

- `src/state/types.ts`、`reducer.ts`、`initialState.ts`：全局状态、动作和纯 reducer。
- `src/state/storage.ts`：版本化 localStorage 持久化与恢复。
- `src/state/eventLogger.ts`：核心事件日志。
- `src/state/AppStateContext.tsx`：Provider 与 hook。
- `src/components/PrototypeDebugPanel.tsx`：场景、事件和重置调试入口。
- `src/state/state.test.ts`：持久化、合并、动作回放与比较规则测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`
