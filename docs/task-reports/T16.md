# T16 实现全局悬浮比较栏

## 实施摘要

建立全局 ComparisonProvider 和悬浮比较栏。0 个时隐藏，1 个时提示继续选择，2–5 个可开始比较；重复添加给出反馈，第 6 个必须明确选择替换对象。

## 改动文件

- `src/features/comparison/*`：比较动作、悬浮栏和满额替换流程。
- `src/components/FrontstageLayout.tsx`：所有前台页面接入比较 Provider 与悬浮栏。
- `src/styles/global.css`：桌面和移动端悬浮布局。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 0、1、2–5 个作品均有正确显示和启动状态。
- [x] 重复作品不重复加入并提供即时反馈。
- [x] 第 6 个作品不被静默丢弃，要求用户选择替换项。
- [x] 比较选择通过全局状态持久化并可逐项移除或清空。
- [x] 类型检查、测试和构建通过。
