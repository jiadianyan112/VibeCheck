# T38 实现新作品多步骤发布表单

## 实施摘要

在正常且无重复的 URL 检查后创建稳定草稿，进入步骤 2–5 的模块化编辑：自动预填、产品定义、方案与功能、开发与资产。所有字段直接写入持久化 `SubmissionDraft`；自动提取值与用户纠正值分开保存，跨页或重新打开不会丢失。
