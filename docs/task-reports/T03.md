# T03 建立低保真样式基线

## 实施摘要

建立黑白灰设计变量、reset、页面容器、栅格、堆叠、占位媒体、按钮、输入、标签、卡片、表格、弹层、骨架、空状态、焦点与响应式规则，并新增临时样式展示页。

## 改动文件

- `src/styles/tokens.css`：灰阶、间距、边框、圆角、控制高度和页面宽度变量。
- `src/styles/global.css`：reset、布局、控件、状态与响应式样式。
- `src/pages/StyleSandboxPage.tsx`：样式展示页。
- `src/pages/StyleSandboxPage.test.tsx`：组件组和弹层测试。
- `src/app/router.tsx`：接入 `/__sandbox`。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] `/__sandbox` 展示任务书要求的基础元素与状态。
- [x] 灰度线框，不依赖颜色单独表达状态。
- [x] 键盘焦点可见，弹层关闭后返回触发按钮。
- [x] 桌面与窄屏布局无设计性横向溢出；表格提供有标签的滚动容器。
- [x] 类型检查、3 项测试和生产构建通过。
