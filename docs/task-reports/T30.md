# T30 实现详情互动与基础评论

## 实施摘要

补充可持久化的点赞弱信号，并实现绑定作品的四类结构化评论、回复、举报审核和恶意样例折叠。访客评论经登录门控后恢复原正文与类别。

## 验收结果

- [x] 收藏、点赞、关注、分享与比较均在详情页可操作。
- [x] 评论类别覆盖使用反馈、开发问题、复用反馈和状态补充。
- [x] 评论与回复均绑定当前 projectId，不存在独立帖子。
- [x] 登录回跳保留评论正文、类别和回复目标。
- [x] 举报只转入审核并保留历史；固定推广样例默认折叠。
- [x] 点赞明确标为弱信号，不用于质量排序。
- [x] 评论空状态只有下方评论表单这一发布入口。
- [x] 类型检查、105 项测试和生产构建通过。

## 页面入口

- 有评论：`/project/project-quizforge#discussion`
- 折叠恶意样例：`/project/project-pdfquizlab#discussion`
- 评论空状态：`/project/project-papertopractice#discussion`
