# T34 实现比较后的私有决策记录

## 实施摘要

在结构化比较后新增决策表单，支持“继续、调整、复用、暂停”四种行动，受影响字段多选、判断理由、资产关联、比较同步保存及未来项目关联占位。游客可先完整填写，再登录恢复提交。

## 验收结果

- [x] 行动覆盖继续、调整、复用和暂停。
- [x] 受影响字段支持多选并覆盖用户、定位、功能、流程、技术路径和资产。
- [x] 判断理由必填，资产关联可选。
- [x] 未来新项目关联明确标记为后续开放，不伪造已实现能力。
- [x] 游客填写内容在登录弹窗打开和登录完成时保持不变。
- [x] 登录回放生成字段完整且 `visibility: private` 的 DecisionRecord。
- [x] 决策、比较会话、作品顺序和 sessionId 一次性关联保存。
- [x] 同一决策重复回放不会新增记录或重复完成事件。
- [x] 完成态可返回比较或进入个人中心决策锚点。
- [x] 类型检查、lint、132 项测试和生产构建通过。
