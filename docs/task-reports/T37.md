# T37 实现重复作品分流

## 实施摘要

在 T36 查重结果上接入重复作品专用分支。重复时只读取已有档案并展示名称、地址、作者关联和来源，默认主动作进入详情；作者验证必须在提交者明确声明“我是作者且需要管理”后才出现，非同一作品只提供后续证据入口占位。
