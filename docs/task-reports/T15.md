# T15 实现登录门控与全局反馈

## 实施摘要

建立统一登录门控和低保真身份选择弹层；访客动作进入 PendingAction，登录后通过 reducer 精确回放一次。同时提供 Toast、确认框、错误面板和渲染错误边界。

## 改动文件

- `src/features/auth/*`：登录门控、身份选择与动作恢复。
- `src/components/feedback/*`：Toast、确认框、错误面板和 ErrorBoundary。
- `src/app/providers.tsx`：全局接入错误边界、Toast 与登录门控。
- `src/styles/global.css`：反馈和身份选择布局。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 访客操作进入统一登录门控并保留动作上下文。
- [x] 登录成功后动作只回放一次。
- [x] 已登录用户不重复弹出门控。
- [x] Toast、危险确认、服务错误与渲染错误均有统一反馈。
- [x] 类型检查、测试和构建通过。

## 页面入口

全局 Provider 接入；后续业务按钮可直接使用 `LoginGate`。

## 遗留问题

类型检查、52 项单元测试和生产构建均通过。
