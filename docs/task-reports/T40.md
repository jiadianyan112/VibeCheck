# T40 实现作者身份验证分支

## 实施摘要

将已有作品的“我是作者”入口实现为低频人工审核流程。申请人可选择域名控制、代码仓库、原发布账号、公开主页或其他材料；材料保存在持久化私有审核记录中。固定状态覆盖待审核、需补充、成功、失败和归属争议，成功只派生作者关联与编辑权限，争议冻结高风险编辑。

## 前置条件检查

- [x] T37 的重复作品分流和作者验证次要入口已完成。
- [x] T15 的验证请求类型与模拟服务基础已完成。
- [x] 已核对任务书 T40 原文范围，未实现自动验证。

## 改动文件

- `src/pages/AuthorVerificationPage.tsx`：登录保护、五种证明方式、私有材料、人工审核状态、状态历史与成功后的补充引导。
- `src/features/authorVerification/verification.ts`：稳定申请 ID、追加式状态历史、权限派生和争议冻结规则。
- `src/services/verificationService.ts`：pending、changes_requested、verified、failed、disputed 固定审核场景。
- `src/state/*`：验证申请的持久化、兼容恢复与幂等 upsert。
- `src/pages/ProjectDetailPage.tsx`：按当前账号的验证结果显示关联、管理入口或争议冻结，不读取私有材料。
- `src/types/domain.ts`、`src/mocks/userAssets.ts`：补充提交、解决时间和状态历史。
- `src/pages/AuthorVerificationPage.test.tsx`、`src/features/authorVerification/verification.test.ts`：隐私、状态、关联、权限、争议和历史测试。
- `src/styles/global.css`：验证材料、状态和权限边界的低保真布局。
