# T41 实现作品更新流程

## 实施摘要

为已有管理权限的作者实现版本、公开地址、作品状态、复用资产和产品说明更新。提交前显示前值/后值、来源与影响范围；提交后原子写入作品覆盖值、追加式生命周期事件、详情/动态同步和关注者通知。旧地址与事件 changes 保留，暂停或结束必须明确勾选作者声明。

- [x] T39 的稳定作品与事件模型已完成。
- [x] T40 的管理权限与争议冻结判断已完成。

## 改动文件

- `src/pages/ProjectUpdatePage.tsx`：权限判断、更新类型、前后值预览、来源、影响范围、终止状态声明与提交确认。
- `src/features/projectUpdate/update.ts`：五类更新映射、事件/记录/资产生成、旧值保留和关注者通知。
- `src/state/*`：作品覆盖值、追加事件、追加资产、更新记录和通知的持久化原子写入。
- `src/pages/ProjectDetailPage.tsx`：合并更新后的作品、事件和资产。
- `src/pages/ActivityPage.tsx`：合并更新后的作品状态与新增公开事件。
- `src/types/domain.ts`：项目更新类型、来源和记录类型。
- `src/pages/ProjectUpdatePage.test.tsx`、`src/features/projectUpdate/update.test.ts`：地址、状态、版本、说明、资产、权限、详情/动态同步和通知测试。
- `src/styles/global.css`：更新类型菜单与前后值对照布局。
