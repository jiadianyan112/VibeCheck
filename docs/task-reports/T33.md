# T33 实现结构化比较页

## 实施摘要

在持久化比较会话中加入七个维度的横向结构化矩阵：定位、输入输出、流程、功能、实现、当前状态和可复用资产。页面提供维度导航、仅看差异、查看全部、相同项折叠、作品顺序调整及资产快捷区。

## 验收结果

- [x] 2–5 个作品沿稳定列顺序横向比较。
- [x] 定位、输入输出、流程、功能、实现、状态和资产均来自结构化字段。
- [x] 默认仅看差异，可切换全部并按行折叠相同项。
- [x] 未知字段保留原因，不用推测值补空。
- [x] 字段显示核验时效、最后核验时间和可展开证据来源。
- [x] 过期信息仍显示，并有独立视觉提示。
- [x] 异常、暂停和结束状态在作品头与状态行突出显示，其他历史字段不隐藏。
- [x] 资产快捷区显示状态、许可、价格和外链保护。
- [x] 覆盖相同、多差异、未知与过期自动化场景。
- [x] 类型检查、lint、127 项测试和生产构建通过。
