# T32 建立可持久化、可分享的比较会话

## 实施摘要

将全站比较选择统一到 `ComparisonSession`，保留现有 `comparisonProjectIds` 兼容读法；所有入口的添加、移除、替换、排序与清空都会同步当前会话、活动会话编号及本地持久化数据。新增 `/compare/:sessionId` 管理页，用稳定 URL 恢复固定或本地会话，并支持保存与登录合并。

## 验收结果

- [x] 会话支持创建、添加、移除、替换、排序、保存和恢复。
- [x] 重复项与最多 5 项规则由同一模型统一处理。
- [x] 只有达到 2 个作品时才满足正式比较数量规则。
- [x] 悬浮比较栏、桌面导航和移动导航都进入同一个 sessionId。
- [x] 匿名会话、活动会话编号和所有会话均写入 localStorage。
- [x] 登录后合并账户项目，保留匿名选择且总数不超过 5。
- [x] 刷新和直接访问分享路径均可恢复会话。
- [x] 本任务只实现会话管理，未提前实现比较表。
- [x] 类型检查、lint（仅既有 Fast Refresh 警告）、121 项测试和生产构建通过。
