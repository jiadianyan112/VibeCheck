# T12 实现基础组件库

## 实施摘要

将低保真样式基线收敛为无业务耦合的 Button、Input、Tag、Card、Tabs、Modal、Drawer、Table 与反馈组件，并统一在组件沙盒展示。

## 改动文件

- `src/components/ui/*`：基础组件及公开类型。
- `src/pages/StyleSandboxPage.tsx`：组件状态和交互沙盒。
- `src/styles/global.css`：组件状态、抽屉与窄屏规则。
- `src/pages/StyleSandboxPage.test.tsx`：状态、标签页、Esc 和焦点返回测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 基础组件均以明确 props 对外提供。
- [x] 覆盖 disabled、loading、error、focus、empty 状态。
- [x] Modal 与 Drawer 支持 Esc、遮罩关闭和焦点返回。
- [x] Table 在窄屏可聚焦横向滚动。
- [x] 类型检查、测试和构建通过。
