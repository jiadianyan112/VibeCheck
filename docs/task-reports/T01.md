# T01 初始化 Vite React TypeScript 工程

## 实施摘要

初始化最小 Vite、React、TypeScript 单页应用，配置 React Router 依赖、Vitest、Testing Library、Playwright、ESLint 和规定的质量脚本；未创建业务页面。

## 改动文件

- `package.json`、`package-lock.json`：依赖与脚本。
- `index.html`、`src/main.tsx`、`src/App.tsx`：最小应用入口。
- `tsconfig*.json`、`vite.config.ts`、`vitest.config.ts`、`playwright.config.ts`、`eslint.config.js`：工程和测试配置。
- `src/App.test.tsx`、`src/test-setup.ts`：初始化烟雾测试。
- `.gitignore`：构建、测试和原始输入忽略规则。

## 运行命令

- `npm install`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 依赖安装成功。

- [x] 类型检查、单元测试和生产构建通过。
- [x] 默认演示内容已移除。
- [x] 未创建业务页面。

## 遗留问题

首轮测试发现 Vitest 运行时全局 API 未开启，已在本任务内修正；复验后类型检查、1 项单元测试和生产构建全部通过。开发服务器使用同一 Vite 入口，因当前命令安全策略不允许后台启动后自动终止进程，未执行独立 HTTP 探针。
