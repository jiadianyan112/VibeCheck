# T55 完成无障碍与键盘操作检查

## 实施摘要

完成 WCAG A/AA axe 审计、人工语义审计和键盘主流程回归。修复 live region、定义列表、弹层焦点、标签页方向键、移动滚动区与表单错误关联，并保留完整审计记录。

## 前置条件检查

- [x] T54 的 360、390、768 与桌面响应式结构已稳定。
- [x] T53 固定场景和测试数据可复现审计页面。

## 主要改动

- 新增 `@axe-core/playwright`，覆盖游客与登录后的核心页面。
- 新增统一 `useDialogFocus`，为 Modal 和 Drawer 提供焦点陷阱、Escape 关闭与触发点恢复。
- 通用 Tabs 与移动比较标签采用 roving tabindex，支持左右方向键、Home 和 End。
- 修正 Toast live region 与作品详情定义列表的 ARIA／HTML 结构。
- 比较决策、发布多步骤表单和身份材料补充错误关联，并在失败后聚焦首个无效字段。
- 移动发布步骤滚动区可获焦且有明确名称。
- 新增 `e2e/accessibility.spec.ts` 与 `e2e/keyboard-accessibility.spec.ts`。

## 验收结果

- [x] axe WCAG 2 A/AA、WCAG 2.1 A/AA 核心页面零违规。
- [x] 键盘可完成搜索、加入比较、比较决策、登录续办和发布基础流程。
- [x] Modal/Drawer 焦点被限制在容器内，Escape 关闭后恢复到触发点。
- [x] 移动比较标签支持标准方向键行为且只有当前标签进入 Tab 顺序。
- [x] 表单错误有 `aria-invalid`、`aria-describedby` 和明确焦点落点。
- [x] 比较矩阵和移动步骤滚动区可通过键盘访问。
- [x] 卡片标题链接与收藏／比较按钮没有嵌套点击。
- [x] 状态、差异、过期和未知事实均有文字表达，不依赖颜色。
- [x] 57 个测试文件、258 项单元测试全部通过（44.63 秒）。
- [x] T55 Playwright 23 项通过、5 项按设备职责预期跳过。
- [x] typecheck、生产构建和差异检查通过；lint 0 错误。
