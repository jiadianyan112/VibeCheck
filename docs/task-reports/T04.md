# T04 建立完整路由骨架

## 实施摘要

接入前台 P01—P18、后台 A01/A02/A03/A04/A05/A06/A08/A09、样式沙盒和 404 路由。占位页展示页面 ID、名称、路由参数和待实现模块，根路径重定向到作品广场。

## 改动文件

- `src/app/routeCatalog.ts`：页面 ID、路由与待实现模块清单。
- `src/app/router.tsx`：完整路由配置。
- `src/pages/RoutePlaceholderPage.tsx`：统一占位页。
- `src/pages/NotFoundPage.tsx`：404 与返回入口。
- `src/app/router.test.tsx`：关键路由、参数、重定向与 404 测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`
