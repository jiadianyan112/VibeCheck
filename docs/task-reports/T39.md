# T39 实现发布预览与审核状态

## 实施摘要

把 T38 的完整草稿接入发布预览、确认提交和审核状态生命周期。首次提交冻结字段与资产快照并复用同一审核单；固定场景覆盖待审核、需修改、通过和拒绝。通过后从草稿标识生成稳定作品 ID 与首次发布事件，并可在作品详情和公开动态中访问。

- [x] T38 的多步骤草稿、原始提取和持久化已完成。
- [x] 已核对任务书 T39 原文范围与验收标准。
- [x] 工作树改动仅属于 T39。

## 改动文件

- `src/pages/SubmissionReviewPage.tsx`：社区卡片预览、详情摘要、来源说明、提交确认、审核状态、补充材料、撤回和提交版本回看。
- `src/features/submission/review.ts`：审核状态迁移、字段级意见、稳定发布标识、不可变提交快照及发布作品/事件映射。
- `src/pages/SubmitFormPage.tsx`：步骤 5 完成后进入预览；需修改状态可定位回对应编辑模块。
- `src/pages/ProjectDetailPage.tsx`、`src/pages/ActivityPage.tsx`：接入审核通过后生成的作品档案和首次发布动态。
- `src/types/domain.ts`、`src/state/storage.ts`：扩展并兼容持久化审核快照、补充材料、发布标识和撤回时间。
- `src/services/submissionService.ts`：四种固定审核场景统一通过审核生命周期函数返回。
- `src/features/submission/review.test.ts`、`src/pages/SubmissionReviewPage.test.tsx`：审核幂等、字段意见、撤回恢复、发布详情和动态测试。
- `src/styles/global.css`：低保真预览、摘要和审核状态布局。
