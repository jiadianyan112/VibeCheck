# T20 实现最新动态页面

## 实施摘要

使用 LifecycleEvent 构建公开事件流，按日期排列并支持事件类型和学习分类筛选。每条事件展示作品、事件类型、事实摘要、日期、证据入口及详情锚点。

## 验收结果

- [x] 动态仅来自 LifecycleEvent，不由普通字段编辑生成。
- [x] 发布、版本、状态、资产、迁移和复用事件可按时间浏览。
- [x] 筛选状态写入 URL，点击可定位详情时间线节点。
- [x] 暂停和结束采用事实边界文案，技术异常不推断失败。
- [x] 空事件流明确解释原因。
- [x] 类型检查、测试和构建通过。
