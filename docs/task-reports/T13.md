# T13 实现状态、证据与资产组件

## 实施摘要

实现访问状态、新鲜度、完整度、争议、证据抽屉、未知事实、资产卡片与外链确认组件。状态组件覆盖领域枚举的每个值，未知状态不使用猜测替代。

## 改动文件

- `src/components/domain/*`：状态、证据、资产与外链领域组件。
- `src/styles/global.css`：领域组件灰度样式与窄屏规则。
- `src/components/domain/StatusAndEvidence.test.tsx`：完整枚举、证据、未知与外链测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`
