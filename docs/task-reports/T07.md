# T07 创建作品与作者模拟数据

## 实施摘要

创建 12 个固定作品、6 个固定作者和 5 项复用资产，覆盖八个首期子场景、主要访问状态、作者关联状态、完整度、来源和可复用资产。所有 ID、日期和内容固定，无随机生成。

## 改动文件

- `src/mocks/projects.ts`：作品构造与 12 个固定项目。
- `src/mocks/creators.ts`：6 个固定作者。
- `src/mocks/assets.ts`：5 项复用资产。
- `src/mocks/factories.ts`：已知／未知字段事实构造器。
- `src/mocks/projects.test.ts`：覆盖密度、状态和资产测试。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`
