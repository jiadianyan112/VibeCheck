# T23 实现自然语言意图解析模拟器

## 实施摘要

建立确定性的规则解析器，将原始文本映射到目标用户、场景、输入、练习形式和输出，返回高／中／低置信及显式失败；提供受控 IntentEditor 允许用户修订字段。

## 验收结果

- [x] 覆盖 PDF 出题、口语模考评分、背词卡片和不可识别输入。
- [x] 原始文本在成功、部分成功和失败中均完整保留。
- [x] 结构化输出可编辑，未知字段不被猜测补全。
- [x] 规则和解析失败场景有单元测试。
- [x] 不调用外部模型，不生成市场或商业判断。
- [x] 类型检查、测试和构建通过。

## 页面入口

解析器由 T24 的 `/discover` 页面接入；T22 已允许先显示关键词结果。

## 遗留问题

类型检查、75 项单元测试和生产构建均通过。
