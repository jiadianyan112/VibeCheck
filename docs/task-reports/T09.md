# T09 建立模拟 service 层

## 实施摘要

建立 project、search、comparison、submission、verification、notification 和 admin 异步服务，统一类型化结果、错误编号、可配置延迟、取消与固定场景注入。服务返回深拷贝，失败不会修改模拟源数据。

## 改动文件

- `src/services/runtime.ts`、`result.ts`：运行时、场景和类型化错误。
- `src/services/*Service.ts`：七类模拟服务。
- `src/services/services.test.ts`：正常、空、稀疏、错误、局部成功和审核结果测试。
- `src/services/index.ts`：公共服务出口。

## 运行命令

- `npm run typecheck`
- `npm run test`
- `npm run build`

## 验收结果

- [x] 页面后续可仅通过 service 访问数据，无需直接导入 mocks。
- [x] 支持固定延迟、网络错误、服务错误、超时、空结果、局部提取和审核结果。
- [x] 错误包含可追踪 code、类型和重试属性。
- [x] 服务返回类型化深拷贝，失败不修改源数据。
- [x] 6 项 service 测试、总计 28 项测试、类型检查和构建通过。
